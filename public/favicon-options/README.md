# PropSlip Favicon Options

These are draft favicon options that keep the current dark race-stripe background and replace the `P` with a white three-blade propeller mark.

- `propeller-mark-a.svg`: largest simple prop shape for tiny tab sizes.
- `propeller-mark-b.svg`: adds a thin white ring for a more badge-like app icon.
- `propeller-mark-c.svg`: more aggressive, swept racing shape.
- `propeller-mark-d.svg`: compact prop with more negative space around it.
- `propeller-mark-e.svg`: cleaner prop over a dark backing disk for better tiny-size contrast.
- `propeller-mark-f.svg`: broad blade silhouette based on the reference prop profile, with sharper outer tips.
- `propeller-mark-g.svg`: same broad silhouette with a dark backing disk for stronger contrast over the stripe.
- `propeller-mark-h.svg`: more pointed version of F with chiseled blade ends.
- `propeller-mark-i.svg`: chopper-style high-rake silhouette with swept rounded blades and sharper tip shoulders.
- `propeller-mark-j.svg`: same chopper-style silhouette with a dark backing disk for stronger contrast over the stripe.
- `propeller-mark-k.svg`: cleaver-style silhouette with chopped blade ends and sharp corners.
- `propeller-mark-l.svg`: same cleaver-style silhouette with a dark backing disk for stronger contrast over the stripe.
- `propeller-mark-m.svg`: compact cleaver-style silhouette tuned for small favicon sizes.
- `propeller-mark-final.svg`: option J propeller shape on the original race-stripe background, without the dark backing disk.

The live site still uses `public/favicon.svg`.
